# Daily Manager Briefing

Run my daily manager automation. Do ALL of the following steps:

## 1. Important Emails → Slack DM

Check my recent emails (last 12 hours). Identify anything important:
- Escalations, action items assigned to me, leadership asks, incident notifications, launch blockers, approvals needed
- Skip: newsletters, automated notifications, FYI-only threads, marketing

For each important email, send me a Slack DM summary with:
- Subject line
- Sender
- 1-2 sentence summary of what's needed from me
- Urgency (🔴 urgent / 🟡 action needed / 🟢 FYI-important)

## 2. Unread Slack DMs

Check my unread Slack DMs. Summarize any that need my attention:
- Who messaged me
- What they need
- Send me a consolidated Slack DM with all pending DMs I haven't responded to

## 3. Last-Minute Calendar Invites

Check my calendar for today and tomorrow. Flag any meetings added in the last 24 hours:
- Meeting title, organizer, time, attendees
- Send a Slack DM alert for each new invite with context on what it might be about

## 4. 1:1 Meeting Prep

For any 1:1 meetings happening today:
- Look up the person's recent CRs, Taskei tasks, and any open items
- Check if there are any relevant tickets or blockers involving them
- Send me a Slack DM 30 minutes before each 1:1 with:
  - Person's name and meeting time
  - Their recent work activity (CRs submitted/reviewed, tasks completed/in-progress)
  - Any blocked items or risks
  - Suggested talking points

---

If any step fails due to missing permissions or tool access, report what worked and what didn't so I can fix the setup.
